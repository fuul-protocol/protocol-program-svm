# Program Upgrade Guide

## Prerequisites

- Anchor CLI installed (`anchor-cli 0.32.1+`)
- Solana CLI installed
- Node.js + Yarn
- Network keypairs in `./keys/<network>/` (admin.json, program.json, etc.)

## Steps

### 1. Sync keys

Copy the network's program keypair and sync:

```bash
cp ./keys/$NETWORK/program.json ./target/deploy/fuul_solana-keypair.json
anchor keys sync --program-name fuul_solana --provider.cluster $CLUSTER
```

`$CLUSTER` values: `devnet` or an RPC URL for other networks.

### 2. Compute PDAs

Check if `constants.rs` needs updating:

```bash
yarn scripts compute-pdas --network $NETWORK --program-id $PROGRAM_ID
```

Compare the output with `programs/fuul-solana/src/constants.rs`. If values match, no changes needed. PDA values only change on fresh deployments, not upgrades.

### 3. Build

```bash
anchor build
```

### 4. Verify upgrade authority

```bash
solana program show $PROGRAM_ID --url $CLUSTER -k ./keys/$NETWORK/admin.json
```

Confirm the `Authority` field matches your admin key:

```bash
solana-keygen pubkey ./keys/$NETWORK/admin.json
```

Also check the admin has enough SOL:

```bash
solana balance $(solana-keygen pubkey ./keys/$NETWORK/admin.json) --url $CLUSTER
```

### 5. Execute upgrade

```bash
anchor upgrade --program-id $PROGRAM_ID \
  --provider.cluster $CLUSTER \
  --provider.wallet ./keys/$NETWORK/admin.json \
  target/deploy/fuul_solana.so
```

### 6. Update SDK IDL

For Solana networks (devnet, mainnet, testnet):

```bash
cp target/idl/fuul_solana.json packages/fuul-solana/src/idls/solana/$NETWORK.json
yarn prepare:sdk && yarn build:sdk
```

For Fogo networks:

```bash
cp target/idl/fuul_solana.json packages/fuul-solana/src/idls/fogo/$NETWORK.json
yarn prepare:sdk && yarn build:sdk
```

## Notes

- Never manually edit IDL files — they are generated by `anchor build`
- The `constants.rs` PDA values are derived from the program ID. They only change if the program ID changes (i.e., a fresh deployment, not an upgrade)
- After upgrading, the program ID stays the same — only the binary is replaced
